# Mandelbrot Canonical n=200 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grow the vendored CLBG mandelbrot fixture from the fuel-shrunk n=128 to the canonical n=200, granting the CPU-fuel budget through a scoped sandbox policy so the global runaway guard stays tight.

**Architecture:** The fixture source, a new deny-all-except-console sandbox policy, a regenerated 5011-byte golden PBM, updated metadata sha, and a test that passes `--sandbox` all land together as one atomic green change. A separate, non-blocking bonus task investigates codegen fuel reduction. A final task updates the maturity doc + memory and ships the PR.

**Tech Stack:** Rust (kali CLI + runtime), wasmtime fuel metering, JSON sandbox policy (schema v1), Python 3 for the independent golden reference.

## Global Constraints

- Working branch: `mandelbrot-n200` (already created; spec already committed there).
- The golden PBM MUST be pinned against an **independently generated** canonical reference (not kali's own output) — circularity is disallowed.
- Any codegen change MUST leave the golden **byte-identical** (mandelbrot is pure computation) and MUST ride the full gate, not just the fixture test.
- The bonus fuel-reduction task MUST NOT block shipping n=200.
- Sandbox policy validation rejects `0` for unused numeric limits — use `null` (verified: E5510 otherwise). `console: true` is required (`Kali.writeStdoutBytes` is Console-gated).
- Full gate: `kali_lexer`, `kali_common`, `kali_types`, `kali_codegen`, `kali_cli`, `kali_parser`, `kali_runtime` all green; `cargo fmt --check` clean.
- Integration per repo convention: push a PR and self-merge (`gh` authed as rahulmutt; run `gh auth setup-git` if git can't read credentials).

- [ ] **Step 5: Generate the independent canonical reference and install it as the golden**

Run this (writes the reference straight to the golden path):
```bash
python3 - crates/kali_cli/tests/fixtures/benchmarks/mandelbrot-benchmark-v1.expected.pbm <<'PY'
import sys
n = 200
out = bytearray([80, 52, 10])          # "P4\n"
out += b"200 200\n"                     # header (11 bytes total)
for y in range(n):
    Ci = 2.0 * y / n - 1.0
    byte = 0; bits = 0
    for x in range(n):
        Cr = 2.0 * x / n - 1.5
        Zr = Zi = Tr = Ti = 0.0
        for i in range(50):
            Zi = 2.0 * Zr * Zi + Ci
            Zr = Tr - Ti + Cr
            Tr = Zr * Zr
            Ti = Zi * Zi
            if Tr + Ti > 4.0:
                break
        bit = 1 if Tr + Ti <= 4.0 else 0
        byte = ((byte << 1) | bit) & 0xFFFFFFFF
        bits += 1
        if bits == 8:
            out.append(byte & 0xFF); byte = 0; bits = 0
open(sys.argv[1], "wb").write(out)
print("reference bytes:", len(out))
PY
```
Expected: `reference bytes: 5011`. This reference is generated from the CLBG algorithm independently of kali's codegen — it is the pin, not a copy of kali's output.

### Task 2 (BONUS, non-blocking): Codegen fuel-reduction investigation

**Files:**
- Read: `crates/kali_codegen/src/emit/operators.rs`, and the array-index/store emit path (grep below).
- Possibly Modify: whichever emit path shows a clean redundancy.

**Interfaces:**
- Consumes: nothing new — operates on existing codegen.
- Produces: (optional) reduced fuel for all arithmetic-heavy programs; a recorded before/after fuel number.

- [ ] **Step 1: Measure the current per-op cost precisely**

Temporarily instrument `crates/kali_runtime/src/execute.rs`: after `start.call(...)`, add `eprintln!("KALI_FUEL={}", budget.saturating_sub(store.get_fuel().unwrap_or(0)));` (capture the budget into a local before `set_fuel`). Rebuild, run the n=200 fixture with `--sandbox`, record the number. **Revert the instrumentation immediately after** (`git checkout crates/kali_runtime/src/execute.rs`). Baseline to beat: 65,429,267.

- [ ] **Step 2: Inspect the hot-path lowering**

Read the float arithmetic and array-store emit paths:
```bash
grep -rn "I64Store\|bounds\|memory_grow\|f64\|Mul\|Add" crates/kali_codegen/src/emit/operators.rs | head -40
```
Look for: redundant `Tr + Ti` recomputation (fixture lines 22 & 25 recompute the same sum), per-store bounds checks that could be hoisted, or float box/unbox churn in the inner loop. Note the single most promising clean win.
