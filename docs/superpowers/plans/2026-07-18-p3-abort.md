# Stage P3 — AbortController/AbortSignal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real `AbortController`/`AbortSignal` lowering (global-heap abort cell, `.abort()`, `.signal`, `.signal.aborted`, compile-time `instanceof AbortSignal`) plus the abort-handle-only captured-binding allowlist entry, acceptance-driven by the webBaselineSmoke prefix running byte-for-byte against node.

**Architecture:** `new AbortController()` allocates one 8-byte cell on `__alloc_global` (never reclaimed); controller and signal are the same i64 pointer ("abort handle"), distinguished purely by compile-time provenance. A new `Repr::AbortHandle` variant carries provenance through inference; codegen mirrors it with an `abort_handle_locals` provenance set (the `event_target_locals` pattern) and a position allowlist at the single bare-identifier read site. Capture soundness falls out of the global-heap pointee: allowlist entry 3 in `unlowered_capture_denied` admits captured abort handles by value.

**Tech Stack:** Rust workspace (`kali_common`, `kali_types`, `kali_codegen`, `kali_cli`), wasm-encoder, cargo test.

**Spec:** `docs/superpowers/specs/2026-07-18-p3-abort-design.md` (approved 2026-07-18).

```rust
//! Abort-handle emission (Stage P3): receiver-handle loads under the
//! position allowlist, and the abort-cell store/load idiom. The handle is
//! an i64 pointer to one 8-byte `__alloc_global` cell holding the aborted
//! flag; controller and signal are the same handle.

use wasm_encoder::{Function, Instruction, MemArg};

impl<'a> crate::FunctionEmitter<'a> {
    /// The single entry every abort receiver load flows through (mirrors
    /// `emit_growable_receiver_handle`): sets the position-allowlist flag,
    /// emits the receiver, restores the flag. Any abort-handle read NOT
    /// coming through here stays denied E5506 (default-deny).
    pub(crate) fn emit_abort_receiver_handle(
        &mut self,
        function: &mut Function,
        receiver: LirNodeId,
    ) -> EmittedValue {
        let previous = self.admit_abort_handle_read;
```
