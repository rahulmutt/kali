# Stage P4 — URL + URLSearchParams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real `URL` and `URLSearchParams` lowering — compile-time-parsed from string-literal constructor args — so the web-baseline `URLSearchParams`/`URL` block runs byte-for-byte against node, extending the acceptance prefix past the current abort/event cutoff.

**Architecture:** `new URL(<lit>)` is parsed at compile time with the already-vendored `url` crate; its five accessed components (`href/origin/pathname/search/hash`) are interned as string literals into a 6-slot heap struct, plus one slot holding an embedded `URLSearchParams`. `new URLSearchParams(<lit>)` is parsed with `form_urlencoded` at compile time into a growable pair-store (`[k0,v0,k1,v1,…]` over the existing `ARRAY_HANDLE_TAG` growable machinery); its query/mutation methods are synthetic guest fns over `__streq` + growable scan/push. Two new `Repr` variants (`Repr::Url`, `Repr::UrlSearchParams`) carry provenance through inference; codegen mirrors the `Repr::AbortHandle` discipline — provenance sets (`url_locals`/`usp_locals`), a single position-allowlist flag at the identifier read choke point, and default-deny (E5506) everywhere else. Zero host glue: the same wasm runs under `kali run` and in-browser.

**Tech Stack:** Rust workspace (`kali_common`, `kali_types`, `kali_codegen`, `kali_cli`), `wasm-encoder`, `url = "2.5"` + `form_urlencoded`/`urlencoding` (already workspace deps), cargo test.

**Spec:** `docs/superpowers/specs/2026-07-20-p4-url-usp-design.md` (approved 2026-07-20).

//! struct of interned component handles + an embedded USP; USP is a growable
//! `[k0,v0,…]` pair-store. Handles are escape-restricted: every read flows
//! through the position-allowlist entry points here or fails closed E5506.

use wasm_encoder::{Function, Instruction, MemArg};

pub(crate) enum UrlMember { Href, Origin, Pathname, Search, Hash, SearchParams }

impl<'a> FunctionEmitter<'a> {
    /// `<url-ident>.<component>` where the base is a proven URL local and the
    /// property is one of the six known members. Returns (base_id, member).
    pub(crate) fn url_member_read_parts(&self, node: LirNodeId) -> Option<(LirNodeId, UrlMember)> {
        let n = self.node(node);
        if n.kind != LirNodeKind::Value || n.children.len() != 1 { return None; }
        let base_id = n.children[0];

        let base_name = base.text.as_deref()?;

            "href" => UrlMember::Href, "origin" => UrlMember::Origin,
            "pathname" => UrlMember::Pathname, "search" => UrlMember::Search,
            "hash" => UrlMember::Hash, "searchParams" => UrlMember::SearchParams,
            _ => return None,
        }))

    /// (mirrors emit_abort_receiver_handle).

        self.admit_url_handle_read = true;
        let v = self.emit_node(function, receiver, true);
        self.admit_url_handle_read = prev;
        v

            let (ko, kl) = self.strings.intern(k);

            [crate::encode_string_handle(ko, kl), crate::encode_string_handle(vo, vl)]

        // <implement per growable.rs; see Task-3 note>
    }
