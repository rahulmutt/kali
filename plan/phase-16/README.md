- Grow inference inside the bounded-inference contract only.

- Mirror accepted and rejected cases in checker baselines and CLI JSON diagnostics.
- Current progress: bounded library-export inference now also preserves obvious nullish-coalesce fallback literals in the cheap signature slice when the branch choice is statically known across JS, TS, JSX, and TSX inputs, including nullish-wrapped function bindings such as `null ?? fn`, `void 0 ?? fn`, and their async-function counterparts, keeping the public export metadata a little less conservative without widening the cross-module boundary contract.

- Each promoted semantic slice has parser/checker/lowering/runtime evidence.
